NOIR - APPLICATION UPDATE AND ITEL 202 PROJECT PACKAGE

1. APPLICATION
Open Noir-Internet-Cafe-Python-MySQL/noir-internet-cafe in VS Code.
Follow START-HERE.md. The folder must contain app.py and requirements.txt.

If upgrading, preserve your original .env and MySQL database. Back up first.
Create a fresh virtual environment if extracting to a new location; do not copy an old .venv.
Run migrate-db before opening the updated app. The migration preserves existing records and adds inventory/maintenance tables.

Admin pages now include Inventory, Maintenance and Reports. Enter the confirmed IP address at Inventory > Add/Edit device > IPv4 address. This records the address; configure DHCP reservations or the PC separately. Members cannot create bookings or access admin tools.
